## Recent engineering work

At **Rakuten**, I connect data science with reusable analytics services:

- **Multi-agent telecom analytics:** Built LangGraph and LangChain workflows that route natural-language questions between ClickHouse/SQL analytics and Qdrant-based semantic retrieval.
- **Access-aware retrieval:** Designed authorization-aware vector retrieval and integrated response caching to reuse repeated analytical work.
- **Backend services:** Built Python and FastAPI services with role-based access, reusable analytics APIs, and a plugin-based architecture for adding tools and data sources.
- **Data pipelines and insights:** Developed distributed ingestion and processing with Spark, ClickHouse, and Airflow. Used telecom behaviour and network analysis to support customer segmentation and partner campaigns.
- **Capacity forecasting:** Developed a cell-tower bandwidth forecasting model using AWS SageMaker, with a Lambda prediction workflow and monitoring and alerts through CloudWatch and SNS.

These are high-level summaries of professional work; employer source code and datasets are not included in my public repositories.
